# GeoSafe SR — Interview Preparation Guide

## Navigation

This folder contains everything you need to confidently defend your GeoSafe SR project in any technical interview.

### Folder Structure

```
interview-prep/
│
├── README.md                          ← You are here
├── master-prompt-template.md          ← Reusable prompt for any future project
│
└── geosafe-sr/
    ├── 01-project-overview.md         ← "Tell me about your project" answers
    ├── 02-architecture-and-design.md  ← CNN, ResNet, SE blocks, PixelShuffle
    ├── 03-ml-and-deep-learning.md     ← Training, inference, optimization, GPU
    ├── 04-loss-engineering.md         ← L1, Sobel, LPIPS, RaGAN deep dive
    ├── 05-data-engineering.md         ← Rasterio, 12-channel TIFFs, WorldStrat
    ├── 06-debugging-and-challenges.md ← The 3 biggest bugs and how you solved them
    ├── 07-system-design-and-scaling.md← "How would you scale this?" answers
    ├── 08-resume-defense.md           ← Every number on your resume, verified
    └── 09-behavioral.md              ← "Why this project?" "Biggest failure?"
```

### How to Use

1. **Before an interview**: Read `01-project-overview.md` and `08-resume-defense.md` first.
2. **For ML/DL interviews**: Deep dive into `03-ml-and-deep-learning.md` and `04-loss-engineering.md`.
3. **For System Design rounds**: Focus on `07-system-design-and-scaling.md`.
4. **For behavioral rounds**: Read `09-behavioral.md`.
5. **For future projects**: Copy `master-prompt-template.md` and fill it in.
